# SEVER notification rhythm v115

SEVER notifications should feel like one calm assistant, not independent feature spam.

## Cadence
- 08:30 local — Start of day. One overview of today's remaining tasks and habits.
- 14:00 local — Day rhythm. Send only when something useful remains. Do not repeat future timed tasks that will get their own 15-minute reminder.
- 20:30 local — Day close. If unfinished work remains, suggest one small next step; if the day is complete, celebrate briefly.

## Timed tasks
A task with an exact time keeps the dedicated automatic cadence:
- 1 day before — preparation;
- 15 minutes before — start cue.

## Habits
Habits are bundled into the day rhythm. Never send one push per habit. Motivation should use progress context (for example completed/remaining), vary copy, and avoid guilt or failure language.

## Noise limits
- At most three rhythm notifications per local day per device.
- Skip empty morning/afternoon slots.
- Afternoon should not nag about a future timed task before its own reminder.
- Exact-time reminders may be additional because they are event-specific.
- Rhythm notifications use normal priority; only the 15-minute task reminder is high priority.

## Product principle
The Home screen and notifications should answer the same question: “What matters now?” The app should reveal complexity progressively instead of showing every control at once.
