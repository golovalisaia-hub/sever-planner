# SEVER PWA

Быстрый личный планер для GitHub Pages. Работает без сервера и без API-ключа, устанавливается на телефон и сохраняет данные в браузере устройства.

## Возможности

- 30-дневный челлендж Python + ПДД;
- любые личные задачи и привычки;
- быстрый ввод фраз вроде `завтра английский 20 минут`;
- «Северный курс» — подсказка следующего шага;
- автоматический перенос просроченных личных задач;
- карта прогресса и недельный итог;
- светлая и тёмная темы;
- резервная копия и восстановление JSON;
- офлайн-режим и установка как PWA.

## Публикация

Загрузите содержимое этой папки в корень репозитория GitHub. Затем откройте `Settings → Pages`, выберите `GitHub Actions` в разделе Source и запустите workflow `Deploy SEVER to GitHub Pages` во вкладке Actions.

Важно: данные хранятся отдельно на каждом устройстве. Не добавляйте API-ключи в этот репозиторий.
